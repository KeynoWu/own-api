## 二、P1 五条（Lead 已全部独立复核）

### P1-1 存储型 XSS：上游畸形 usage → 管理台 `tip.innerHTML`
- **D-01**｜`src/translate.ts:460-468`、`475-485`（无归一）vs `489-493`（流式**有** `typeof number` 闸）→ `src/gateway.ts:1229` 非流式直接 `Object.assign` → `db.json` 落字符串 → `src/admin.ts:524` 原样出 → `web/index.html:351` 字符串拼接 → `:165` `num()` 原样返回 → `:419` `tip.innerHTML`
- **Lead 独立实证**（自己的 mock 上游 + 真网关 + 真落库，并用 `eval` 跑项目自身源码行）：
  ```
  落库 completionTokens = "<img src=x onerror=\"globalThis.__pwned=1\">" | typeof = string
  聚合后 pout = "0<img src=x onerror=...>" | num(pout) 原样返回
  赋给 tip.innerHTML = <div>输出<span>0<img src=x onerror="globalThis.__pwned=1"></span></div>
  含可执行标签 = true | 含事件处理器 = true
  CSP(:6) script-src 含 'unsafe-inline' → 内联 handler 不被拦
  ```
- **影响链（本项目最严重的一条）**：可执行脚本 → 读 `localStorage.lm_token`（管理令牌，§五-L4）→ 调全部管理 API → 经「接入 Agent」写本机配置文件。畸形 usage 还会让图表画成 `NaN`，用户为排查**更可能去悬停**，触发概率不低。
- **修复**：根因收口在服务端（`usageFrom*` 出口做 `Number.isFinite(v) && v > 0 ? v : 0`，与 `mergeUsage` 同规）；展示层把 `:419` 的 `innerHTML` 改 `el()`/`textContent`。

### P1-2 `/api/snippet` 非回环仍吐明文 vkey
- **SEC-B-01**｜`src/admin.ts:894` 只闸了 `key` 字段，`:896-899` 的 `curl/openaiSdk/claudeCode/codexCli` **四字段无条件内插** `${vk.key}`

- **影响**：A-M 掩码战役被单点绕过；前提是持有 admin token 的非回环调用方（LAN 控制台 / 反代 / 令牌外泄）
- **修复**：`const reveal = isLocalish(c)` 统一到全部字段，非 reveal 一律占位符

### P1-3 写进 agent 配置的 baseUrl 取请求 `Host` 头
- **SEC-B-02**｜`src/admin.ts:676-677` `reqBase()` 用 `c.req.header('host')`，与同处注释「URL 永不来自请求」及 `agent-import` 文件头「零外部入参」承诺矛盾
- **Lead 独立实证**（`Host: evil.example`）：`plan.baseUrl = http://evil.example`，首个步骤 `{"apiKey":"sk-lm-***","baseURL":"http://evil.example/v1"}`

## 六、为什么这些缺陷能全绿通过

基线是 472 + 220 全绿，而 P1-1（XSS）与 P1-5（窗口口径）都是真缺陷。原因集中在**测试姿态**：

1. **前端聚合逻辑零覆盖**（D 的 T-1）：473+223 条钉**没有一条跑过** `addAgg`/`from`/`startT`/`buckets`。窗口口径这类缺陷在钉的视野之外。
2. **源码字符串钉冒充行为钉**（D-12）：DR-17 的守护钉是 `html.includes('l._n || 1')`——它只证明「这行字还在文件里」，不证明「账本按窗口过滤了」。**把不变量钉成字面量，等于把机制钉成了仪式**。
3. **数据形状假设**：所有 e2e 都用自家 mock 的**规范** usage（数字），没有任何一条喂过畸形上游（P1-1 的触发条件）。
4. **类型门缺席**（D-17）：`ci.yml` 不跑 `typecheck`，类型层面的口径不一致（如 `Usage` 字段被 `|| 0` 静默放宽）没有第二道网。
